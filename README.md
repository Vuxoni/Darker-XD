# Darker-XD

Adobe XD still doesn't have an official dark theme. Following this tutorial, you'll be able to change the theme to a dark theme with charcoal panels and light text. Unfortunately, canvas color can't be changed this way.

# Requirements
- Adobe XD (compatible version)
- Any text editor (VSC, N++...)

# Compatibility
Tested with XD 61.0.12.1

# Instructions
1. First of all, we'll need to give us access to the `C:\Program Files\WindowsApps` folder by editing Windows Registry. To do this, download the [Take Ownership](https://www.tenforums.com/tutorials/3841-add-take-ownership-context-menu-windows-10-a.html) .reg file and run it. Accept everything when prompted.

2. Navigate to `C:\Program Files\WindowsApps` and find the folder that begins with `Adobe.XD_`. Open the `Themes` folder that's inside it.

3. In `Themes` folder, find `General.xaml` file. Right-click on it, then click `Take Ownership` (if you're using Windows 11, you might need to click `Show more options` before you can click `Take Ownership`).

4. Copy `General.xaml` and make a backup somewhere on your device (for example on Desktop).

5. Open `General.xaml` from `Themes` folder with your prefered text editor.
